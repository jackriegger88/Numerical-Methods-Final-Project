# Hastings-Powell Chaotic Food Chain Model

A Python implementation of the Hastings-Powell (1991) three-species food chain model using a custom 4th-Order Runge-Kutta (RK4) integrator.

## Overview
This software simulates the population dynamics of a three-level trophic system:
1. **Resource (X):** e.g., Grass
2. **Consumer (Y):** e.g., Rabbits
3. **Top Predator (Z):** e.g., Foxes

The model demonstrates deterministic chaos and the formation of a "Strange Attractor."
